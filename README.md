# Mis proyectos — ArmonIA

Tu primer espacio en ArmonIA: el **mapa de tu vida y tus proyectos**. Ábrelo con Claude Code en VS Code y escribe
**empecemos**: tu agente te acompaña a ordenar tus metas, tus áreas y qué merece ser un proyecto. Te habla en tu idioma.

**Es para ir haciendo algo valioso mientras David, tu arquitecto, prepara la estructura del proyecto que le
contaste.** Lo que escribas aquí se queda **en tu equipo**. Cuando David monte tu proyecto (en 2 días hábiles), te llegará un
correo con tu código personal y tu agente pasará todo a tu espacio privado.

Guía: https://armonia.3spark.net/
